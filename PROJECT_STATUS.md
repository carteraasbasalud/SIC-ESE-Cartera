# 💼 Proyecto: Cartera (Sistema de Gestión de Cartera ESE Assbasalud / SIC ESE)

## 📌 Información General
- **Entidad:** Assbasalud ESE / Hospitales Públicos Manizales
- **Ubicación:** `G:\PROYECTOS-IA\Cartera\`
- **Entregable:** `Cartera_SIC_ESE_Entregable.zip`

## 🚀 Componentes y Arquitectura
1. **Backend (`/backend`):**
   - API de procesamiento y conciliación de cuentas por cobrar.
   - Generación de reportes bajo estándares de la Superintendencia Nacional de Salud (Circular Única / Reporte 81).
2. **Frontend (`/frontend`):**
   - Tableros de control con filtros por EPS, rangos de edad de cartera (0-30, 31-60, 61-90, 90-180, 180-360, >360 días).
   - Exportación de informes y conciliaciones.
3. **Scripts de Ejecución y Automatización:**
   - `Iniciar_SIC_ESE.bat` / `Detener_SIC_ESE.bat` / `Instalador_SIC_ESE.bat`.
   - `Subir_a_GitHub.bat`.
4. **Datos y Cortes:**
   - Estado de Cartera Corte Diciembre 2025.
   - Reporte 81 Plataforma Abril 2026.
   - Documentos de entrega y manuales técnicos (`.pdf`, `.rtf`).

## 📋 Temas Pendientes / Próximos Pasos
- Nuevos cortes de información y conciliaciones automáticas con EPS.
- Mejoras en la reportería para auditorías de Supersalud.
